利用例 ​

このページでは、VitePress をどんな場面で使えるかを具体例で紹介します。

例1：社内勉強会資料のアーカイブ ​

  • セッション単位でフォルダを分ける
  • 勉強会後も内容を残せる
  • 参加できなかった人も後から読める
text
sessions/
├─ 01-vitepress/
├─ 02-slidev/
├─ 03-c4/
└─ 04-adr/

「喋らなくても伝わる資料」を作れるのが強みです。

例2：設計・技術検討メモ ​

  • 技術選定の理由
  • 試した案と却下理由
  • 決定に至った背景

これらを 時系列で Markdown に残すことで、
後から見返したときの理解コストが下がります。

（→ 次回の ADR セッションと相性が良い）

例3：チーム内ナレッジ集 ​

  • よく使うコマンド
  • ハマりポイントのメモ
  • プロジェクト固有ルール

README が肥大化する代わりに、
ページを分けて整理できます。

向いていないケース ​

  • 動的なユーザー操作が必要な画面
  • フォーム入力・DB連携が前提のアプリ

VitePress は 読むための資料 に特化したツールです。

よくあるミス ​

❗ GitHub Pages でリンクが壊れる

md
[NG] /sessions/01-vitepress/
[OK] sessions/01-vitepress/
  • サブパス配信では絶対パスに注意
  • 相対パスを基本にすると安全

まとめ ​

  • Markdown を「資料」として整えたいなら有力
  • 勉強会・設計メモ・ナレッジ共有と相性が良い
  • 小さく始めて育てられる
